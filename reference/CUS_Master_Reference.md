## 3. 色卡制作規範

### 3.1 四大原理（最重要）

> **注意**：秩序・馴染み・明瞭性の3原理は、何色の色卡でも必ず**3種色相（不多不少）**。類似性のみ1種色相。四大原理すべて**トーンとは無関係**、トーンは自由。

| 原理 | 歩数ルール | 色相数 | 例 |
|------|-----------|--------|-----|
| **秩序原理** | 2+2（連続2歩間隔） | **3種** | `1Y + 3YG + 5G` または `9GB + 11B + 13V` |
| **馴染み原理** | 4+5（4歩+5歩） | **3種** | `7BG + 11B + 16P` または `20R + 24YO + 5G` |
| **類似性原理** | 0歩 | **1種** | 同一色相の異トーン（vv-1Y + pl-1Y + dl-1Y + dk-1Y） |
| **明瞭性原理** | 対角線(12歩) ± 2歩 | **3種** | `1Y + 13V + 11B` または `1Y + 13V + 15P` |

#### 明瞭性原理 詳細

基準色相Aに対して：
1. 対角線色相 = A + 12歩（例：1Y→13V）
2. 対角線の±2歩 = 対角線 - 2歩 または 対角線 + 2歩（例：13V→11B または 15P）
3. 組み合わせ：`A + 対角線 + (対角線 - 2歩)` または `A + 対角線 + (対角線 + 2歩)`

#### 歩数の数え方

色相番号の差 = 歩数。例：1Y(#1) → 3YG(#3) = 2歩。24YO(#24) → 2Y(#2) の場合は (24→1→2) と跨いで2歩。

### 3.2 色卡版式規範

| 項目 | 仕様 |
|------|------|
| 言語 | **全日语**（原理名、トーン名、色相名、副題すべて） |
| キャンバス幅 | **996px**（高さは自動） |
| 背景 | 純白 #FFFFFF |
| 色ブロック配置 | **横方向に並列** |
| ブロック間隔 | グループ内で**完全均一**、色相グループで意図的に離さない |
| 罫線 | **一切使用禁止**（ブロック境界線・区切り線ともに入れない） |
| 色番号文字色 | 全色番号とも純黒 #000000（深色・浅色で白黒切り替え禁止） |
| フォント | 全テキスト **ヒラギノ角ゴ Std W8** に統一 |
| 複数グループ | 縦方向に並列、グループ間は統一間隔 |
| 色番号形式 | 1行で折り返さない（例：`dp-19R`） |
| タイトル | 原理名のみ（歩数・公式は書かない） |

### 3.3 フォント

| 用途 | フォント |
|------|---------|
| 色卡色番号（dp-19R等） | **ヒラギノ角ゴ Std W8** |
| 中国語タイトル | **PingFang SC** |
| 日本語タイトル・副題 | **ヒラギノ角ゴ** |

### 3.4 BU/YU の扱い

- **デフォルト**：BU/YUは強制統一しない。自由に跨いでOK。
- **ユーザーが明示的に「アンダートーンを考慮」と言った場合のみ**：全BUまたは全YUに統一し、色卡にBU/YUを表記。

### 3.5 流行トレンド色卡の場合

流行トレンド配色から色卡を作る場合、色卡に**配色の情緒的雰囲気を表す名前**（日本語）を追加する。例：「静寂の朝」「灼熱の鼓動」等。
